# 教員向け指導計画作成アプリ - 簡易版デモ

## 概要
Gemini AIを活用して、指導計画を自動生成するWebアプリケーションです。

## 機能
- **単元別指導計画の生成**: 学年、教科、単元、授業時数を入力して指導計画を作成
- **月間指導計画の生成**: 学年、教科、月を指定して月間計画を作成
- **結果のコピー**: 生成された計画をワンクリックでコピー

## セットアップ手順

### 1. 必要なパッケージのインストール
```bash
cd teaching_plan_app/backend
pip install -r requirements.txt
```

### 2. バックエンドサーバーの起動
```bash
cd teaching_plan_app/backend
python app.py
```

サーバーが http://localhost:5000 で起動します。

### 3. フロントエンドの起動
別のターミナルで以下を実行:

```bash
cd teaching_plan_app/frontend
python -m http.server 8000
```

ブラウザで http://localhost:8000 にアクセスしてください。

## 使い方

### 単元別指導計画の作成
1. 「単元別指導計画」タブを選択
2. 学年、教科、単元名、授業時数を入力
3. 「指導計画を生成」ボタンをクリック
4. 生成された計画が表示されます

### 月間指導計画の作成
1. 「月間指導計画」タブを選択
2. 学年、教科、月を選択
3. 「月間計画を生成」ボタンをクリック
4. 生成された計画が表示されます
